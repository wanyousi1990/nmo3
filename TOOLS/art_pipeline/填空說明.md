# 規格 JSON 要填哪裡

規格檔在 `TOOLS/art_pipeline/specs/`。掃描後節點路徑已填。組裝**不再要求每張圖都齊**；沒匯出的 Sprite 維持原圖。

## 檔名對照

```json
{
  "node": "Pelvis/Torso/Sprite_Torso",
  "krita_layer": "Torso_Naked",
  "fill": false
}
```

- `node`：場景裡已有的 Sprite。掃描已填，不要隨便改、也不要為了沒畫完去刪。
- `krita_layer`：跟 Krita 圖層名、PNG 檔名（不含 .png）相同。
- `fill`: 給你標記「這格我自己還要畫」；組裝不靠它決定套不套，只看資料夾裡有沒有檔。

開頭是 `_` 的圖層（底稿）會被跳過。

## 女主／怪物都可

在 Godot 工具裡選場景、點選 visual 根即可：

- 女主 idle：`TSCN/character_body_2d.tscn` → `Visuals/Normal_Visual`
- 女主 dash：同一場景 → `Visuals/Dash_Visual`
- 女主 H：同一場景 → `Visuals/OL_H_Visual/H_Pose_01`（02、03…）
- 女怪：`TSCN/female_monster.tscn` → `Visaul`
- 壯怪：`TSCN/strong_monster.tscn` → `Visaul`

獨立的 `TSCN/h_pose_01.tscn` 仍可當參考，女主已不引用它。

## Krita Scripter

檔案：`TOOLS/art_pipeline/krita_plugin/export_from_scripter.py`

裡面兩行路徑，換姿勢時改：

```
SPEC_PATH = r"D:\FILES\GOODGAME\nmo3\TOOLS\art_pipeline\specs\h_pose_01.json"
PNG_DIR   = r"D:\FILES\GOODGAME\nmo3\TOOLS\art_pipeline\_preview\from_krita"
```

或在專案根目錄跑：

`py TOOLS/art_pipeline/pipeline.py export-krita-script`

Krita 沒有的層會跳過，不會逼你先畫 Naked。
