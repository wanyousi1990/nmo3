# 怎麼改規則（不用會寫程式）

你只要改**文字檔**。Agent 之後會照新內容做事。

## 平常改哪裡

| 你想改什麼 | 打開這個檔 |
|---|---|
| 遊戲哲學、H 規則、美術命名、刪檔流程 | `DOCS/NMO3規範.md` |
| 開發進度、主圖 12 張、要做／不做 | `DOCS/開發進度掌控表.md` |
| 劇情、美術方向、玩法取捨、銷售／系列（2～7 款） | `DOCS/系列中長期構想.md` |
| 一句話硬規定（每次對話都要守） | `.cursorrules` 或 `.cursor/rules/00-nmo3-core.mdc` |
| 跳多遠、關卡間隙 | `.cursor/rules/movement-limits.mdc` |

Cursor 左側檔案樹點進去就能改，存檔即可。或跟對話說：「規範加上：某某」或「進度表把某某改成已做」。改原則時規範與 `.cursorrules`／`00-nmo3-core.mdc` 要一起對，不要只改一處。

## 檔案長什麼樣子

- `.md`：一般說明，你看得懂就能改。
- `.mdc`：開頭有三行 `---`，那是給 Cursor 看的開關。**`alwaysApply: true` 表示每次對話都帶上。** 不要刪那三行，只改下面的標題與條列。

## 不要改的

- `.godot/`（編輯器快取）
- 沒說要動的 `.tscn` 路徑（搬資料夾會讓圖消失）

## 改完怎麼確認有生效

新開一則對話，問：「現在 @export 的規則是什麼？」若答案跟你改的一致就對了。舊對話可能還記舊規則。
