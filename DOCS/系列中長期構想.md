## 系列一句話

第二款女主墮落成魅魔王后 → 之後幾款都在同一條世界線上：攻堅、監獄與地下實驗室、徵人調教、災後人形怪、最後拼完整世界觀並遇到第一代女主。

**幾乎每款換女主**（第六、七款同一人）。美術可沿用前作角色當 NPC／頭目，但玩家操作的身體要換，避免「同一張臉賣第二次」。

## 對第三款（現在）的約束

做劇情、關卡口氣、頭目、預告、商店文案時對過這些，避免跟後面幾款打架：

- 舞台是**魅魔辦公大樓攻堅**，不是監獄、不是實驗室、不是災後街道。
- 玩家是**新女主**，不是第二款那張臉。
- 頭目是**魅魔王后**（第二款女主墮落後）。打贏之後不是「世界清乾淨」，而是**男性押送失敗、王后逃跑**——給第四款留監獄／實驗室。
- 玩法增量是**輕近戰**。不要在這款先做遠戰、不要先做成解謎收集為主（那是第四款構想）。
- 美術：新畫預算仍以進度表 **12 張主圖** 為準；王后與舊怪沿用第二款。

## 事業路線（兩階段條件）

### 第一階段：成人短線作養一般向

開一般向專案前，以下全部達到：

1. 至少上架一款**完整非 AI** 作品（美術流程不靠 AI 也做得出來）
2. 連續兩款**準時完成**
3. 成人作每季淨收入能付開發成本（素材、委託），例如每季 2 萬台幣以上
4. 追蹤者穩定成長（每款上架時記 Ci-en、X 追蹤數）

### 第二階段：上班養到全職

離職前以下全部達到：

1. **連續 2～3 季**每季淨收入 ≥ 6.6 萬台幣（約薪資一半）
2. 單一款收入不超過總收入一半（靠作品庫長尾，不是一款爆紅）
3. 存好 6～12 個月生活費
4. 家人同意，了解收入會起伏

算法參考：售價 990～1,320 円，每套實拿約 75～100 台幣；新作每季約 400 套＋5 款舊作各每季約 60 套長尾，才接近門檻。照上面時程，最早約第五、六款（2028～2029）。

### 檢查點

- 2027/2 底：第三款首週、DLsite 回覆、上班後實際時數 → 定第四款做法
- 第四款上架後 3 個月：售價調整後每套實拿、是否超過第二款
