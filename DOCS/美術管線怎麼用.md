# 美術管線怎麼用（給你看的）

這不是 MCP。MCP 已關掉。這是「Krita 畫圖層 → 匯出 PNG → 換進現有場景」的本機工具。

## 它在幹嘛

**以你匯出的圖為準。** 資料夾裡有哪張 PNG，就套到場景裡已經存在、檔名對得上的 Sprite。沒匯出的節點（例如 Naked 還沒畫）維持原圖，**不用刪節點，畫好再匯出一次即可。**

女主 `Normal_Visual`、`Dash_Visual`、`H_Pose_*`，以及怪物的 `Visaul`，都用同一套。只換貼圖，不改你調過的位置、z_index。

正式進遊戲前，先組到 `TOOLS/art_pipeline/_preview/` 給你看。你點頭再按正式組裝。

## 圖層／PNG 怎麼取名

`部件_狀態`，例如 `Torso_Naked`、`Breast_L_Bra`、`Torso_Clothed`。

部件：Torso、Pelvis、Hip_L／R、Thigh_L／R、Calf_L／R、Arm_L／R、Forearm_L／R、Breast_L／R、Head、HairFront、HairBack、Pussy、Eye、Mouth

狀態：Naked、Clothed、Bra、ShirtOpen、Lewd、Iku、Overlay

畫布建議 192×192，同一姿勢同一 pivot。名稱前面加 `_` 的層會被跳過（底稿）。

女主 idle 的 `Sprite_Torso`＝Naked、`Sprite_Torso2`＝Clothed，對應 `Torso_Naked.png`、`Torso_Clothed.png`。

## Godot 按鈕（不要打路徑）

開啟 `TSCN/art_pipeline_tool.tscn`，看 Inspector：

1. **target_scene**：點資料夾圖示選 `.tscn`（女主或怪物）。
2. 按 **0 載入目標場景**。左邊 Scene 樹會出現 **視覺根候選**（Godot 選節點只能看到這個工具場景裡的東西，所以不會把整隻女主掛進來）。
3. **visual_root**：Assign，選 `視覺根候選` 底下例如 `Visuals／Normal_Visual`。選完 **visual_root_path** 會自動填真正路徑。不確定就按 **0b**。
4. **png_folder**：選 Krita 匯出 PNG 的資料夾。
5. **art_folder**：正式組裝要複製到的 `ART/` 資料夾。
6. **1 掃描**：可選。寫出 `specs/*.json`（給 Krita 對檔名）。
7. **2 預覽組裝** → 看 `_preview/`。
8. **3 正式組裝** → 寫進場景與 `ART/`。

`python_exe` 預設 `py`，不行就改 `python`。

## 指令（專案根目錄，通常不用打）

```
py TOOLS/art_pipeline/pipeline.py list-roots TSCN/character_body_2d.tscn
py TOOLS/art_pipeline/pipeline.py scan-tscn TSCN/character_body_2d.tscn --pose-root Visuals/Normal_Visual
py TOOLS/art_pipeline/pipeline.py assemble --scene TSCN/character_body_2d.tscn --pose-root Visuals/Normal_Visual --png-dir TOOLS/art_pipeline/_preview/from_krita
py TOOLS/art_pipeline/pipeline.py assemble ... --apply
py TOOLS/art_pipeline/pipeline.py selftest
```

Krita：外掛在 `TOOLS/art_pipeline/krita_plugin/`，或跑 `export-krita-script`。Scripter 裡的 `SPEC_PATH` 與 `PNG_DIR` 仍是路徑；Godot 這側已改成選。

細節見 `TOOLS/art_pipeline/填空說明.md`。
